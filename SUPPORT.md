# Getting help

- **Bug or incorrect render:** Open an issue using the matching template, with reproduction steps and minimal input files.
- **Usage question:** Check the [README](README.md) and [docs/](docs/README.md) first. If something is still unclear, open an issue with the **Question** label.
- **Security vulnerability:** Report it privately via [SECURITY.md](SECURITY.md) rather than a public issue.

## Out of scope

This issue tracker is strictly for `ror`. Issues about the following will be closed:
- Roblox account issues, bans, purchases, or specific Roblox games.
- Requests to download assets, models, or places you do not own, or to bypass Roblox moderation or permissions.
- Cheats, exploits, or injectors.

Maintainers work on this project in their spare time, so responses may take a few days.
